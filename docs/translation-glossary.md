# 中文翻译术语表

本仓库翻译为中文时，优先让面向用户和 agent 的说明自然、可执行；同时保留会影响运行、检索或来源准确性的专有名词。

## 保留原文

- 品牌、产品、组织、人物和仓库名：Lenny's Podcast、Claude Code、Refound AI、RefoundAI/lenny-skills、Shreyas Doshi、Marty Cagan 等。
- skill 目录名、命令、路径、配置键、frontmatter key、URL、协议名和 package 名：`skills/`、`SKILL.md`、`.claude/skills/`、`npx skills`、`description`、`name` 等。
- 通用行业缩写和产品术语：PM、PRD、OKR、ICP、ARR、PMF、LLM、AI、B2B、BD 等。
- 直接引述可保留英文；必要时在引述后的解释中用中文说明含义，避免误改来源文字。

## 翻译策略

- 标题、说明、步骤、问题、常见错误、安装和贡献说明翻译为中文。
- 文件结构、Markdown 链接目标、代码块和命令逐字保留。
- frontmatter 的 `name` 保持原样；`description` 翻译为中文，但保留 "Use when..." 触发语义。
- 参考资料中的英文原始 quote 优先保留；`Insight`、`Tactical advice` 等解释性文本可在后续批次翻译。
