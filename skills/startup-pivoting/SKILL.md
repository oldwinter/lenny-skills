# Startup Pivoting

使用来自 2 位产品领导者的框架和洞察，帮助用户决定何时以及如何 pivot startup。

## 如何提供帮助

当用户请求 pivoting 相关帮助时：

1. **评估 current state** - 询问 traction、已经尝试多久，以及学到了什么
2. **评估 possibilities 是否 exhausted** - 判断他们是真的尝试了所有可能，还是只尝试了 idea 的一个版本
3. **挑战 pivot magnitude** - 大多数 founders pivot 幅度太小；帮助他们考虑是否需要 200% pivot，而不是 10%
4. **应用 Four Ps framework** - 从 Problem、Persona、Product 和 Positioning 四个维度评估变化

## 核心原则

### 你是否 exhausted the possibilities？
Stewart Butterfield: "The decision is about have you exhausted the possibilities?" Pivot 应该来自对已尝试事项的 rational analysis，而不是对 failing idea 的 emotional attachment。和 current approach 拉开距离，才能诚实 evaluate。

### 大多数 pivots 都太小
Todd Jackson: "Most founders do a 10% pivot, and what they need to be doing is a 200% pivot." 当卡在 pre-PMF 时，small adjustments 很少能突破。考虑你是否需要 fundamentally change approach，而不是 tweak existing one。

### 使用 Four Ps framework
从四个维度评估 pivots：Problem（你是否在解决正确 problem？）、Persona（你是否 targeting the right customer？）、Product（你的 solution 是否是正确 approach？）和 Positioning（你的 framing 是否正确？）。问题通常不是单一维度，而是组合。

### 保持 rational distance
对 idea 的 emotional attachment 会阻止 founders 看清事实。最好的 pivot decisions 来自像 outside investor 一样评估自己的 company。

## 帮助用户的问题

- "到目前为止你尝试了什么？每次尝试学到了什么？"
- "如果你是 outside investor 在看这家公司，你会得出什么结论？"
- "这是对 current approach 的 tweak，还是 fundamental rethink？"
- "Four Ps（Problem、Persona、Product、Positioning）中哪个可能错了？"
- "和你正在考虑的方案相比，200% pivot 会是什么样？"
- "你是真的 exhausted the possibilities，还是只是试累了？"

## 需要提醒的常见错误

- **Pivoting too small** - 需要 200% changes 才能找到 PMF 时，却只做 10% changes
- **Emotional attachment** - 因为 sunk cost 而继续，而不是基于 potential 的 evidence
- **Pivoting too quickly** - 还没真正学到 current approach 为什么不 work，就改变方向
- **Only changing one P** - 通常多个 dimensions（problem、persona、product、positioning）需要一起改变
- **Pivoting without a thesis** - Random pivots 没有帮助；你需要关于哪里错了的 specific hypothesis
