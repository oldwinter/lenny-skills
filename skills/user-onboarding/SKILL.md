# User Onboarding

使用来自 4 位产品领导者的框架和洞察，帮助用户设计有效 product onboarding。

## 如何提供帮助

当用户请求 user onboarding 相关帮助时：

1. **理解 aha moment** - 询问 key value moment 是什么，以及 users 需要多快到达那里
2. **设计 first 30 seconds** - 强烈关注 signup 后立刻发生什么
3. **应用 game design principles** - 使用 game design 中的 progressive disclosure 和 reward mechanics
4. **连接到 retention** - 确保 onboarding 能把 early user experience 推向 long-term engagement

## 核心原则

### Make the first 30 seconds magical
Grant Lee: "We are going to do everything we possibly can to make the first 30 seconds of the product feel magical." User experience 的最初瞬间是 word-of-mouth growth 的主要 driver。这里值得 disproportionate investment。

### Retention wins 来自 early experience
Dan Hockenmaier: "Very often I think the biggest wins in retention come from inflecting the early user experience." Onboarding experience 是 long-term retention 的最大 lever，而不只是 initial activation。

### Design from onboarding outward
Merci Grace: "I would design the game from the onboarding experience." 使用 game design principles，把 onboarding 作为其余 product 建设的 foundation，而不是 afterthought。

### 移除通往 aha moment 的 blockers
Cam Adams: "We worked a lot on the onboarding process in the last couple of months of launch and that was really pivotal because the product features were there but there was this thing holding people back." Product features 可能已经 complete，但 invisible friction 会阻止 users 体验它们。

### 避免常见 onboarding anti-patterns
跳过 carousels、non-native frameworks，以及不提供 value 的 explanatory screens。尽快让 users 进入 core product experience。

## 帮助用户的问题

- "Users 第一次体验 product core value 的 single moment 是什么？"
- "User signup 后的 first 30 seconds 会发生什么？"
- "Signup 和 aha moment 之间有哪些 friction？其中哪些可以移除？"
- "你是否看过 real users 走完整个 onboarding，并观察他们在哪里 struggle？"
- "User 多快能做一件 meaningful 的事，而不只是 view something？"
- "如果像 game tutorial 一样设计，onboarding 会是什么样？"

## 需要提醒的常见错误

- **Explanation screens instead of action** - Users 通过 doing 学习，而不是通过阅读 doing 的说明
- **Delaying the aha moment** - Signup 和 value 之间的每个 screen 都是 potential dropoff point
- **Carousels and tooltips** - 这些 patterns 往往说明 product 本身不够 intuitive
- **Treating onboarding as separate** - Onboarding 应该被设计为 core product 的一部分，而不是 bolted on
- **Ignoring the first 30 seconds** - 大多数 users 在这里决定是否继续 invest
