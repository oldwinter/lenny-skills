# Retention & Engagement

使用来自 29 位产品领导者的框架，帮助用户提升 retention 和 engagement。

## 如何提供帮助

当用户请求 retention 相关帮助时：

1. **理解 retention curve** - 询问当前 retention shape，以及 drop-off 发生在哪里
2. **识别 aha moment** - 帮助定义 users 第一次体验到 value 是什么样
3. **评估 habit formation** - 判断他们是在为 habitual use 还是 occasional use 构建
4. **设计 retention loops** - 创建能随时间 compounding user value 的机制

## 核心原则

### Retention 对 subscription businesses 是 gold
Albert Cheng: "User retention is gold for consumer subscription companies. If you don't retain your users, then a lot of the onus is on getting them to pay on day one." Retention 会降低立即 monetization 的压力，也是 subscription success 的 primary driver。

### Products 应该越用越好
Sarah Tavel: "The test for me, of whether you're building a product that has the ingredients to create a retentive product on a micro level, just at the user level, is that the product should get better the more you use it, and you'll have more to lose by leaving it." 真正 retention 来自 product 随时间创造 accruing benefits 和 mounting loss。

### Daily return 是最大问题
Jackson Shuttleworth: "What Duolingo really focuses on is, how do we help users build habits around language learning? Getting user come back the next day is the biggest problem to solve." 对 habit-forming products，next-day return 是最关键 metric。

### Onboarding 是最高杠杆 retention investment
Kristen Berman: "I've consistently seen that improving onboarding is one of the highest leverage opportunities for both signup conversion and increasing long term retention. Getting people to your aha moment more quickly and reliably is so incredibly important." 在 onboarding 中加速 time to value 会贯穿整个 user lifecycle 产生 compounding effect。

### 用 data 定义 aha moment
Hila Qu: "I think [the aha moment] as a moment, as a first time a user experienced value of your product... At GitLab we actually did a bunch of analysis. We ended up have something along the line of two users, two features used in the first 14 days." Aha moment 应该由与 retention 相关的 data correlation 定义，通常包含 multi-user 或 multi-feature milestones。

### 创造 mounting loss
留存好的 products 会让 users 感到离开会失去更多。这可能是 data、customization、social connections 或 accumulated history。

### 聚焦 core loop
优秀 retention 来自一个反复交付 value 的 core product loop，而不是把 notifications 或 gamification 叠在弱 product 之上。

## 帮助用户的问题

- "你在 funnel 哪个位置失去最多 users？First session、first week，还是 first month？"
- "哪个具体 action 完成后，与 long-term retention 最强相关？"
- "Retained users 拥有什么，而 churned users 缺少什么？"
- "你的 product 如何随着使用次数增加而变得更好？"
- "如果 user 今天停止使用 product，会失去什么？"
- "新 users 多快能到达 aha moment？"

## 需要提醒的常见错误

- **Notification spam** - 试图通过更多 notifications 驱动 retention，而不是改善 product
- **Undefined aha moment** - 不知道哪种 experience 与 retention 相关
- **Slow time to value** - 复杂 onboarding 延迟第一次 user value
- **No mounting loss** - Product 不随时间积累 user-specific value
- **Optimizing activation over retention** - 只关注让 users 进来，却不确保他们留下
